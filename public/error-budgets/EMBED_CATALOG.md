# Error Budgets embed catalog V1

Base URL: `https://ortiz-luis.github.io/error-budgets/embed/`

All modules read sanitized publication artifacts generated by the GitHub Pages workflow. The embed renderer never reads `dashboard.json` directly.

## Global modules

- Freshness: `?view=freshness`
- Operations overview: `?view=overview&ids=1q,2q,movement,initialization,readout,addressability`
- Fidelity comparison: `?view=fidelity&ids=1q,2q,movement,initialization,readout,addressability`
- Gap to target: `?view=gaps&ids=1q,2q,movement,initialization,readout,addressability`
- Top gaps: `?view=top-gaps&ids=1q,2q,movement,initialization,readout,addressability`
- Priority actions: `?view=actions`
- Operations at risk: `?view=at-risk&ids=1q,2q,movement,initialization,readout,addressability`
- Operations on track: `?view=on-track&ids=1q,2q,movement,initialization,readout,addressability`

## Per-operation modules

Supported operation IDs: `1q`, `2q`, `movement`, `initialization`, `readout`, `addressability`, plus optional prototype `analog`.

For each operation ID `<id>`:

- Current KPI: `?operation=<id>&view=kpi`
- Error budget decomposition: `?operation=<id>&view=decomposition`
- Known vs unknown attribution: `?operation=<id>&view=attribution`
- Contributors / evidence: `?operation=<id>&view=contributors`
- Gap & actions: `?operation=<id>&view=gap-action`
- Technical provenance: `?operation=<id>&view=provenance`
- Literature anchors: `?operation=<id>&view=literature`
- Validated history: `?operation=<id>&view=history`

Backward compatibility: `?operation=<id>` defaults to the Current KPI view.

## Canonical action coverage

V1 contains three synthetic canonical action records for `2q`. Other operations intentionally render `No canonical action registered yet for this operation` in the Gap & actions module until an action is explicitly registered in Git. This is preferable to inventing action data in the presentation layer.
